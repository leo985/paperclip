# AI任务的组织与席位视角（2026-11-12）

侧栏菜单、页面标题及面包屑统一为“AI任务”。组织 owner/admin 和实例管理员默认组织视角，可切换我的工单；operator/member/viewer 默认且仅可使用个人视角。个人范围为直接分配给登录用户，或分配给其当前负责的已登记 DSP7 席位的任务；支持多个席位，无席位仍展示直接分配的任务并提示联系管理员绑定。

这是任务数据访问边界，不只是一项前端筛选。服务端从当前数据库的组织角色、席位归属计算范围，列表与 blocked count 在分页之前应用边界，查询参数不能扩大范围。搜索匹配集合、模糊回退、结果与聚合、提取服务同时限制范围；详情、评论和 issue 授权拒绝访问他人任务。需求分析列表与旧详情入口依据当前任务分配关系执行相同过滤，不继续以创建时 ownerUserId 代替当前权限。现有公司边界和 agent 授权仍保留，后台执行不使用请求上下文中的隐式查询过滤。角色／席位缓存仅限请求内，新的请求重新读取归属；分页缓存键包含服务端计算的个人范围。

不改变派单、任务状态、席位绑定或数据库结构。生产增量发布基于最新线上文件，保留其他改动及旧静态资源。发布验证与回执将在验证完成后补充。
