# 新建 Claude 复用执行电脑现有配置

## 入口

新建原生 Claude 智能体默认显示“使用本机已有配置”，点击“检查并使用本机配置”。可切换到“使用网站密钥或登录”，保留之前的官方和第三方中转站连接。

“本机”指所选执行环境的机器，不是浏览器所在机器。检查读取该环境内已有的 Claude 配置及登录。

## 配置规则

- 用户级设置/登录可用：不填写工程配置文件；网站不注入凭证、地址或官方账号绑定。
- 凭证仅在 Harness 工程设置里：填写执行电脑上的绝对 JSON 文件路径，通过 CLI `--settings` 读取；文件内容不上传，不复制原始密钥到平台。
- 指定文件的其他设置，包括权限规则，也由 Claude 加载。额外指定 settings.local.json 不等于自动合并 Harness 目录的全部工程设置。
- 本机模式采用 CLI，不创建新秘密；模型默认留空跟随本机，可在下一步显式选模型。
- 连接步骤及创建前均检查所选环境；创建保存已检查的环境 ID，防止实例默认环境变化导致运行换机器。
- 本机模式不启动官方登录检查生命周期，不绑定或回退到网站官方连接；后续更换环境需重新配置和检查。
- 此入口针对原生 Claude 智能体；Paperclip Runner 保留原有连接方式。

## 实现

AgentProviderConnection 增加本机来源选择、工程配置文件输入和连接检查。NewAgentSetup 传递 settings 参数，跳过平台凭证路径，展示来源，创建前再次检查并保存环境。帮助智能体主题同步说明三种来源及 worktree 场景。
