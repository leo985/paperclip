# P3 交付工作台与报表实施

日期：2026-10-25。用户要求 P3 提前实施；本批为现有可信数据上的只读汇总，不开放尚未完成的 P1/P2 执行流程。代码与帮助已更新，未发布生产。

## 使用入口和交付范围

协同工作台 → 交付工作台与报表；席位统计也提供入口。组织内路由 `/delivery-workbench`，筛选保存在 URL。

- 任务与过程：跨需求分析、研发（含设计和关联评审）、QA、未分类领域；展示业务状态、最近运行状态、真实阶段事件、会话覆盖/收尾/缺口/正文不可用数量。对话正文仍通过原任务详情按权限查看。
- 统计报表：上海时区日、周、月、季度、年；按项目、席位、执行时负责人及领域筛选。普通成员只看本人当前席位和历史会话；管理员可看本组织全部。
- CSV：导出当前筛选下全部席位汇总，不受任务分页影响；含分母、未知值、口径和生成时间，防公式注入，不含会话正文和凭据。
- 验收材料清单：按项目保存的不可变来源版本逐项显示范围、新鲜度及正式材料缺口；分页，不把来源“完成”替代正式证据。

## 统计口径

| 项目 | 规则 |
| --- | --- |
| 当前在手 | 当前未结束叶子任务去重；不声称是历史期末快照 |
| 开始/交付/取消 | 期间内不可变首次事实；排除模拟事实，主任务不重复计数；未采集不推断 |
| 领域 | 许可固定的 `executionRoute.capability.kind`；不从标题、对话猜测；旧运行未分类 |
| 历史归属 | 会话当时负责人，固定许可的项目；当前任务移项目、席位换负责人不迁移历史运行 |
| 执行/等待 | 根据执行事件90秒有效覆盖，按期间裁剪；同席位/负责人取并集，执行优先于等待 |
| 未知 | 仅受管会话跨度内没有有效执行/等待证据的时间；无会话直接显示未知；整席位离线另见原统计 |
| 空闲 | 无任务的有效席位 idle 心跳，扣除执行/等待重叠；项目/领域筛选无法归属或缺少有效心跳时返回 null |
| Token | 本期成本账本累计差额，运行去重；输入/输出/缓存、计量覆盖和最终回执分别展示；无回执不是零 |
| 费用 | 只汇总实际 reported 记录，USD；unpriced 单列，不猜中转站价格 |
| 质量 | 交付后14天 Jira 显式关联缺陷观测，按执行时负责人及席位匹配；出现关联缺陷完整成熟工单 / 完整观测成熟工单；另列全部成熟工单与观测覆盖率 |

任务页运行状态是最近状态，时间和用量是所选期间；查询历史周期不会把最近状态伪装成历史快照。历史质量队列为期间交付工单，截至查询时的14天观测，不宣称能恢复旧版质量快照。缺少固定项目/领域证据的历史事实不分摊给筛选范围；无筛选总数可能更多。

当前父子结构用于避免主单重复计数，尚无历史父子结构回放。相同会话关联的续传运行通过 bindings 去重计量；运行域按会话主运行固定路由分类，跨领域应创建独立会话。

## 验收与依赖边界

来源版本可以证明记录了哪些条目/主子工单，不能证明正式业务通过。清单中分析、设计、代码评审、构建环境、用例、QA、风险、Tracker 和验收结论保持 unverified，`readyForAcceptance=null`。没有新增自动派发、审批或上游状态写入。

后续仍须依赖 P1/P2 补齐真实分析/评审/QA执行、版本化交付证据与准入引擎，才能将上述待核验项变成实际核验结果。Tracker 领域工时、负责人确认归因 Bug 率尚未接入；本批只完成可观测部分和明确缺口的展示。

## 接口与安全

- GET `/api/companies/:companyId/delivery-insights`：默认 mine；严格验证周期、日期、组织项目与分页，成员不能指定其他负责人。
- GET `/api/companies/:companyId/delivery-insights/acceptance?projectId=…`：组织已纳管来源版本清单，20条/页。
- 只读取会话元数据和 phase/execution 事件，不读取或返回正文、工具输出、adapter配置及密钥。无写接口、无新增数据库迁移。
- 报表一般查询2万行，事件20万行保护；超出整份失败，不返回部分总数。当前仍在应用层汇总，公司数据量大时可能先触发上限；后续应做数据库预聚合，不把小范围筛选承诺为无限规模查询。
