# 组织来源接入与月度浏览

## 已实现

- 来源页只要求组织、轻舟凭据与项目 Jira 连接席位；保存后进入当前项目的月度条目页，保留查询月份。
- 单条号和跨月范围收进“更多操作 → 补录指定条目”，已知条目深链接仍可展开补录。
- 配置就绪时自动读取当前月份；切换月份自动读取，支持手动刷新与错误重试。
- 月度查询缓存按公司、项目、来源修订、月份隔离；失败不自动重试，避免重复登录。切换月份清空批量选择，不沿用其他月份的数据。
- 按计划开始日期排序，缺少日期的条目放在末尾。保留按编号、标题、负责人筛选、同步安排和批量只读同步。
- 组织来源的浏览与同步不授予执行权限，不更改正式评审及编码准入。

## 数据边界

月份指轻舟排期月份，不是条目创建日期。当前已验证接口提供组织月度排期，没有完整未排期需求清单接口；页面及帮助均明确范围。已知未排期条目可通过单条补录核对，完整“未排期”视图待来源合同验证后实现。

## 验证与发布

UI 类型检查、构建、设计 token 检查与来源组件的两个回归测试通过。ego-browser 在隔离上游数据、真实本机路由与数据库上验证了首次配置、保存跳转、自动月度读取、键盘切换月份自动加载及单条补录展开收起。

仅发布静态前端资源及帮助，不重启服务，不修改数据库、现有席位客户端或正在执行的任务。发布记录见同日 `organization-monthly-flow-release.json`。
