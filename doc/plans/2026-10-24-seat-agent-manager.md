# 个人席位隐藏 Agent 层级与受限配置身份修复

个人席位编辑身份区域隐藏 ReportsToPicker，说明人类负责人由管理员指定。独立智能体改为“上级智能体”和“选择上级智能体（可选）”，并解释可留空。只隐藏 UI，不清除既有 reportsTo。

排查确认线上“我的研发电脑”具有 dsp7Seat 登记、outbound 通道和 Jira 接入标记。截图中仍是旧文案，可能是驻留旧页面；未访问截图所属登录会话，不能确定其浏览器状态。同时发现受限 GET /agents/:id 会把 adapterConfig 置空，之前只根据配置识别席位可能漏判。新增 useSeatAgentIdentity：缺少配置时补查当前账号可访问的登记表，核对中及失败时不展示通用操作，可重试。正常服务器 Agent 保留原操作。查询使用已有权限过滤接口，不增加配置可见范围。

验证：107 项动作与表单测试全部通过，含受限配置补查、待核验保护、个人席位隐藏与服务器保留。修复既有测试受默认语言影响的断言：固定测试语言、推理选项按稳定值断言。类型检查、构建、token gates。浏览器线上仅到登录页，未进行认证后的页面验收、未启动实际 Agent。发布静态资源，不重启服务，不修改席位和客户端。
