## 调度协议

规则增加 intakePaused，默认 false，无数据库迁移。暂停接口行锁更新并审计；普通规则保存保留服务器当前暂停状态。发现、首次独占登记、启动请求与启动领取在服务端检查；启动事务重新读取锁定的席位配置，避免陈旧界面绕过。verify 的 start=true 用于新启动；继续运行的 monitor 使用默认 verify，暂停不撤销既有运行授权。本机桥在发现、准备、排队、终端启动前检查暂停；自动请求包含规则版本，恢复后可重新请求失败/过期轮次。

## 数据与安全边界

- 联系人 API 仅限获授权的席位负责人和管理员，同组织、启用的 DingTalk 联邦来源；不返回手机号、邮箱、激活链接或凭证。
- Jira 预览用临时提交 PAT 或该席位加密 PAT，不保存临时 PAT。地址更换需新 PAT；禁止重定向，10 秒请求超时。
- Jira 服务器预览地址须位于 PAPERCLIP_JIRA_ALLOWED_ORIGINS（逗号分隔），默认 http://jira.fingard.com:6001。这个列表仅约束服务器预览。
- 不按名称猜测席位负责人钉钉身份，不自动更换现有通知或启用接单规则。
- 没有可靠席位级 token/耗时汇总，本次不显示推测值；真实运行与用量仍在智能体/任务页面查看。
- 当前 Mac 使用源码桥，发布后重新加载后台 watcher。已安装的其他不可变版本没有自动更新机制，需要显式升级；服务器启动门禁为最终约束。
