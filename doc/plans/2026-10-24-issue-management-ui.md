# 研发工单管理台改版

日期：2026-10-24

## 页面与交互

精简界面的工单入口默认展示管理表格，旧版开关保留原列表。项目、负责人、席位、关键词显式展示；更多筛选包含工单状态、执行状态、优先级及周期执行开关。所有条件保存于 URL，支持单项移除、清空、刷新恢复。保留原列表 / 看板及其分组能力。

快捷视图包括全部、待处理、执行中、等待人工、已阻塞、执行异常、已完成，数量沿用其他筛选。默认隐藏周期执行任务。表格展示编号 / 标题、项目、负责人 / 席位、工单状态、执行状态、最近更新，可配置列、优先级和排序，支持 25 / 50 / 100 条分页。

点击标题或操作打开右侧抽屉，列表及滚动位置保持不变。抽屉按需读取完整说明及原执行状态组件，会话和阶段面板需要进一步展开才加载；完整详情携带列表返回上下文。不会把普通评论自动当作正式确认。

个人命名视图和列设置保存在当前浏览器，按组织及登录账号隔离，最多 20 个；存储失败明确提示。未实现跨设备同步，也不伪装为共享视图。

## 数据证据与性能

组织工单以每批 200 条紧凑元数据、稳定 ID 游标逐批读取，页面只渲染当前页。尚未加载完整时展示 ≥ 与范围说明，失败时不展示为全量统计。不为每行发起会话查询；席位和活动运行批量读取，只有页面可见时轮询。表格不预读会话正文。

工单状态和执行状态分开。运行、等待和异常依赖席位心跳或活动运行；离线不代表本机进程退出；无证据显示待核验。工单已结束但仍有活动证据时展示“结束状态待核对”，不自动停止或恢复。已完成不是已验证交付。统一 Harness 阶段和交付证据在已有会话面板中展示，不按对话推算进度。

## 批量管理与边界

组织管理员可选择当前页并预览批量目标，再确认添加标签、修改普通平台任务项目或负责人。保存前重新读取详情，标签追加保留；已绑定席位、Harness 或执行记录的工单，项目 / 负责人调整跳过，要求在详情处理。逐项展示成功、跳过及失败。筛选或翻页清空选择；所有写入继续由原 API 校验和审计。不提供批量启动、停止或恢复。

## 验证与发布

UI 类型检查、生产构建、token 检查及差异空白检查；执行状态边界采用实际判定函数检查。浏览器使用本地样例数据检查桌面布局、项目筛选、快捷视图和个人保存视图；样例预览替换上下文 / 部分嵌套模块，不等同于线上登录或完整会话回归。不会为验收启动真实工单或写入生产任务。

仅发布静态资源及帮助，无后端 / 数据库 / 客户端改动，不重启服务。资源基线、备份、发布校验和、健康接口和服务 PID 均纳入发布记录。
