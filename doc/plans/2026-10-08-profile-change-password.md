# 个人设置修改密码

日期：2026-10-08

## 功能

入口：左下角头像 → 编辑个人资料 → 修改密码。管理员与普通用户均可修改当前账号密码。填写旧密码、新密码和确认新密码；新密码为 8–128 个字符，与旧密码不同。默认退出其他设备，当前会话由认证服务更新后保留。

沿用 Better Auth 的 `/api/auth/change-password`，服务端校验登录会话和旧密码后保存哈希。前端仅增加接口包装和表单，没有新增管理员越权修改他人密码或重置密码接口。外部 Cloud 账号提示使用所属登录服务。

## 交互与凭证处理

- 密码输入隐藏，支持浏览器密码管理器的 current-password/new-password。
- 提交期间禁止重复操作；错误按旧密码、长度、确认不一致、登录失效等情况中文提示。
- 成功清空密码字段并刷新会话；新会话令牌由认证 Cookie 处理，不写入前端存储。
- 密码不作为 React Query mutation variables 保留；现有请求日志脱敏规则覆盖 currentPassword/newPassword。
- 失效会话提供退出并重新登录操作，复用已修复的退出流程。
- 在线帮助新增“修改个人登录密码”。

## 发布边界

UI TypeScript 检查与生产构建通过。仅更新网页资源，保留旧资源并最后原子切换入口；不重启服务，不修改任何用户的现有密码。

线上核对覆盖入口/主资源哈希、个人设置与帮助的静态页面可访问性、服务健康。不自动修改真实管理员密码，当前未进行浏览器内实际修改密码操作。
