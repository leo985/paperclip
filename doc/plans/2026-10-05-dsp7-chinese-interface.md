# DSP7 Paperclip 简体中文界面（2026-10-05）

## 实现

- 使用现有 i18next / react-i18next 框架，默认语言设为 `zh-CN`，英语作为缺失文案回退语言，HTML `lang` 同步改为 `zh-CN`。
- 增加独立 `interface` 命名空间：`ui/src/i18n/interface.en.json` 和 `interface.zh-CN.json`。中文词库包含 2,274 条文案；界面有约 5,595 处 `uiText` 调用，覆盖导航、任务、项目、智能体、审批、登录、费用、设置及常用组件。
- `uiText` 仅接收应用自身的固定界面文案，不对整个 DOM 或用户输入进行自动替换。保留产品名称、模型名称、代码、命令、路径、API 字段及用户创建的任务内容。
- 任务、智能体、运行、审批和优先级通过 `localizedStatus` 显示中文；后台枚举和请求值继续使用英文。
- 常用日期、相对时间、月度预算后缀改为中文。费用仍以原币种美元显示，不做货币转换。
- AttributionAvatar 保留英文内部标签和识别标记，仅转换可见文本及无障碍说明。

## 范围说明

这是面向当前 DSP7 管理使用的中文化，未宣称 Paperclip 所有未来功能的全部字符串均已翻译。第三方插件、用户或 Agent 生成的内容、运行日志、服务端返回的原始错误、未接入词库的部分实验或高级配置提示仍可能保留英文。缺失文案保留原文，不生成不确定的自动翻译。

新增界面文案应加入中英文词库并使用 `uiText`。新增动态状态应扩展 `localizedStatus`，不得翻译请求中的枚举值。
