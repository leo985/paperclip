# 2026-10-22 本机可见终端显示优化

## 发现

ATSES-491887 最近会话原始终端日志 1,476,674 字节，UTF-8 解码无替换字符。日志包含 54,658 个 ESC 和 1,250 次回到屏幕顶部，是 Claude 全屏界面刷新输出。原接入桥在收到真实窗口尺寸前按 32×120 创建终端；重连直接回放最后 128 KiB，可能从字符或控制序列中间开始。连接结束也缺少完整显示模式清理。启动上下文混入接入协议 JSON 的 Unicode 转义。

日志能够确认上述实现问题；没有保留用户当时画面，不能认定全部视觉异常均由某一个问题导致。

## 修改

- 在 Claude 启动前完成终端首帧尺寸协商，传递真实 TERM、TERM_PROGRAM、COLORTERM。兼容旧客户端的 resize 首帧。
- Unix PTY、Windows ConPTY 都按协商尺寸创建；在进入原始输入模式后才发送首帧，避免早期终端响应留在行缓冲。
- 新增无第三方依赖的 `terminal_display.py`：增量解码 UTF-8；跨网络分块保留完整 VT 控制序列；记录必要显示模式，不保存截断的画面字节尾部。超过上限的异常控制字符串不展示，原始日志照常保留。
- 重连先恢复显示模式，再通过两次相邻列宽的 PTY resize 请求 Claude 重新绘制；不回放旧字节、不注入按键或模型提示。历史会话仍从采集记录查看。
- 原始日志仍记录原始数据，采集、领域阶段、Jira 审批、平台派单和单执行器保护不变。
- Unix/Windows 连接结束均清理鼠标追踪、焦点报告、粘贴模式、光标和备用屏幕。Unix 窗口变化只设标记，由主循环发送，避免信号处理函数重入 socket 写入。
- 仅从交给 Claude 的启动提示去掉桥自有的接入申请/授权/结果 HTML 注释；平台派单时去掉过期的手动启动提示。原始任务说明和授权记录不改写。
- 更新安装包 allowlist，包含新增模块；更新不终止活动 Claude，会话需要重新启动才能使用新版。
