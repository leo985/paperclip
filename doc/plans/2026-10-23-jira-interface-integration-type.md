# Jira 接口联调类型接入

## 需求与实现

席位接单设置增加“接口联调”复选项，服务端允许的工单类型同步扩展至 8 种。已有规则不自动追加类型；负责人勾选并保存后，按原有项目、经办人、状态与权限核验接入。

本机接入桥增加 `接口联调 → integration → dsp-integration-test` 映射。领域目录为 `tickets/integration-{JiraKey}/`，继续使用独占工作树和单执行器保护。任务描述及 `agent inspect` 提供明确技能和状态维护说明，不把联调映射成编码开发。

真实完成额外要求联调上下文与非空报告，并调用 Harness `check_integration_execution_plan.py --stage complete --json` 校验。门禁通过且结果为 passed/partial 才继续原有 Tracker、Jira 与工作树完成校验；partial 在交付评论中明确保留其批准范围，不能当作完整银行链路验收。平台派单不替代技能要求的测试环境、账号、交易及范围确认。

## 使用

1. 部署服务端与网页，已有电脑更新接入桥；Harness 须包含 `dsp-integration-test` 和联调门禁脚本。
2. 席位 → 接单设置 → 工单类型，勾选“接口联调”，保存。
3. 在项目页重新核验对应 Jira 子工单，再派单执行。
