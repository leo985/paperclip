# 退出登录后的认证错误页修复

日期：2026-10-08

## 原因

CloudAccessGate 在缺少登录会话的跳转判断之前呈现 boardAccessQuery 错误。退出会话后 resetQueries 会重取受保护 API，残留的 401 错误先被渲染，导致页面停在 /DSP/dashboard 并显示 Board authentication required。

## 修复

- 非引导阶段、认证模式下，无会话先跳转登录页，残留的权限查询错误不覆盖跳转。
- 本地部署退出成功后取消账户查询、清空账户缓存并进入 /auth，重新建立页面和 QueryClient。健康查询不阻塞导航。
- Cloud 管理的退出流程仍使用 /cloud/logout；权限不足或真实网络错误仍保留原错误处理。

## 发布

UI TypeScript 检查与生产构建通过，仅发布网页资源，保留旧资源且最后原子替换 index.html，无服务端重启、账号权限或密码修改。

本机临时原生编译依赖缺失，通过恢复临时 TypeScript 标准库与原生包元数据解决，未修改项目依赖版本。

当前没有可用的浏览器控制表面；验收范围为类型检查、构建与线上静态资源/登录页面可访问性，不包含用户浏览器的实际点击。
