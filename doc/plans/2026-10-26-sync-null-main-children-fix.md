# SHYH-00043 同步错误修复

## 真实复现

生产已保存 Jira PAT 请求 `/rest/api/2/myself` 返回 200。SHYH-00043 的轻舟登录、条目、分析、组织排期、条目排期及 Jira 查询全部返回 200，但来源归一化抛出“排期主工单缺少子工单数组”。真实排期树中部分主工单的 `children` 为 null，表示无已排期子单。

来源路由又将任何非 QingzhouReadError 统一归为认证失败，并显示“来源凭据未就绪，请核对轻舟账号和 Jira PAT”，因此用户无法判断真实问题。

## 修复

- 完整快照解析器接受 null 子列表为无排期子单，兼容空根节点。不跳过 Jira 工单；未出现在排期中的 Jira 子单仍显示来源差异。
- 保留主工单身份、Jira 子单完整性、父子关系、跨月冲突等核验；对象、字符串、数字等非 null 非数组结构继续拒绝。
- 单独将 Jira secret 解析失败映射到认证错误；保留受控 HttpError(400) 的明确解析错误，其核验状态记为 invalid_response。未知内部异常使用通用来源同步失败提示，不回显内部异常或凭据。

## 验证与发布

30 项来源解析、在线读取、月度及路由测试通过，服务端编译通过。生产主机的临时验证模块使用真实已保存凭据，只读核对 SHYH-00043 成功，返回 39 个工单；未保存条目快照或派发任务。验证模块随后移除。

只替换来源归一化与路由两个后端模块，备份旧模块，检查无活动运行后仅重启平台服务。无需迁移数据库或更新席位客户端。结果见同日 sync-null-main-children-release.json。
