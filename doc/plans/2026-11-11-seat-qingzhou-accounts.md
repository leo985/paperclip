# 席位独立轻舟账号

每个席位在“席位管理 → 具体席位 → 接单设置 → 轻舟账号”配置代表席位身份的账号。席位负责人或组织管理员可保存、更换密码、检查已保存账号的登录状态或移除绑定。配置随席位保留，不按当前登录人选择账号；负责人变更仍遵守现有席位管理权限。

用户名是配置元数据，密码以 JSON 凭据写入现有 `local_encrypted` 加密库。查询接口只返回用户名、配置修订、已配置标记和登录检查状态；不回显密码、token 或秘密引用，也不把凭据放入席位配置、执行包、模型提示或活动日志。首次配置及更换用户名必须提供密码；用户名不变时密码留空保持原值。检查只登录，不保存业务内容，登录成功也不代表具备所有条目的分析权限。

已保存密码且用户名未变时，密码框显示 `****` 占位符；实际输入值仍为空，再次保存不会把占位符当作新密码提交。

新增组织隔离表 `seat_qingzhou_accounts`，迁移为 `0304_lazy_the_call`。配置接口为 `/api/companies/:companyId/dsp7-seats/:id/qingzhou-account` 的 GET / PUT / DELETE，以及 POST `.../check`。所有接口仅对有当前席位授权的真人负责人或管理员开放，机器凭证无权读写。更新、检查和移除要求当前修订；移除保留修订墓碑并撤销秘密，防止旧表单覆盖新配置。秘密解析再次校验所属组织、有效状态和绑定用户名。

分析回写按任务固定的 `seatId` 选择该席位账号，不按发起人、不借用其他席位，也不回落项目来源账号。未配置时保留本地分析结果，显示配置位置，配置完成后由原有管理员重试入口继续保存；不重新运行模型。项目来源账号仍服务于项目列表、排期与条目同步。轻舟仍校验条目分析负责人，平台不改变条目负责人或绕过权限。原有版本指纹、源内容冲突保护、回读确认和正式发布门禁保持生效。

席位账号变更和回写共用组织/席位事务锁，回执记录凭据来源、席位和配置修订。已经成功保存的历史回执保持原状；失败重试使用当前执行席位账号。不会把原项目凭据批量复制给席位。

部署需应用新增迁移、服务端和前端。已有分析自动回写还需上一项功能的新版接入桥上传 `analysis.md`；本次账号配置本身不再改变客户端协议。尚未替用户填写真实账号，也未对真实轻舟进行登录或业务写入验证。
