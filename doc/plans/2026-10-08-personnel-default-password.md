# 人员联邦默认启用与初始密码

日期：2026-10-08

## 已确认规则

用户指定初始密码为 `12345`。同步账号无需管理员生成激活链接，首次登录必须修改初始密码。已有密码、已有账号关联、管理员角色和席位关系不变。

## 实现

- 数据库增加 `personnel_people.require_password_change`，迁移 `0285_wakeful_blue_marvel.sql`。
- 为启用身份源中的有效托管成员、且没有本地密码的账号生成加盐密码哈希。默认值为 12345，可用 `PAPERCLIP_PERSONNEL_INITIAL_PASSWORD` 配置。初始化在事务和人员行锁下检查现有凭证，不覆盖已设置密码。
- 同步后自动执行初始化；部署时补齐既有未配置账号。初始化后旧激活链接失效，联邦页面不再展示逐人激活入口。
- 企业邮箱可直接在普通登录页使用；普通邮箱认证失败后，仅在 401 情况下尝试联邦认证，用户名仍可使用“企业人员账号”模式。
- 首次登录跳转 `/change-password`，旧密码填写 12345，新密码为 8–128 个字符。修改成功后清除首登限制并进入工作台。
- 服务端业务 HTTP API 和实时 WebSocket 都拒绝未完成首登改密的账号；登录、会话、改密及退出接口保留。
- 使用既有 Better Auth 修改密码接口和 Cookie，不新增管理员重置他人密码入口，不向钉钉发送账号消息。
