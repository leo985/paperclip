# Jira 指派驱动的人机协同执行

日期：2026-10-07

目标：组长在 Jira 指派任务，匹配的默认席位在线且空闲后自动执行；遇到业务决策通知席位负责人。

## 推荐：Jira 指派后自动执行

**场景**：组长在 Jira 指派编码、Bug 或设计子工单，研发电脑在线后自动接单，遇到业务决策再通知负责人。

### 一次性配置

1. 进入“席位”，选择自己的电脑，找到 **Jira 指派后自动执行**。
2. 填写 Jira 网站地址及 PAT。PAT 加密保存在 Paperclip 密钥存储中，页面只显示已配置；后续留空表示保留，输入新值可更新。本机通过自己的席位凭证获取这个席位的 PAT，值仅在内存中使用，不写入普通配置或日志。首次启用需配置 PAT。
3. 填写 **Jira 经办人登录名**（不是中文显示姓名）、Jira 项目代号，选择 Paperclip 项目和共享仓库。该仓库须已在本机通过 `harness repo connect` 关联。
4. 填写团队实际允许执行的 Jira 状态，选择工单类型。状态需涵盖本次执行期间允许的状态；未完成但不在允许状态范围的工单不会开工。
5. 配置席位负责人的钉钉接收人及本机 DWS 发送账号，以及提醒和升级间隔。这部分通常只配置一次；自动工单不需要填写下面旧模式的逐单授权列表。
6. 勾选自动执行授权并保存。**启用后会发现当前已有的符合条件未完成工单，也会发现后续指派的工单**。组长负责指派，你无需逐单登记或在本地输入 yes。

### 系统如何执行

本机后台接入桥默认每分钟查询一页 Jira（最多 50 张，并分页继续），按经办人、Jira 项目、工单类型和允许状态发现工作。它不依赖 Jira Webhook；离线期间没有执行，上线后查询补齐。Paperclip 为发现的工单建立持久队列，同一组织同一 Jira 工单不重复建自动任务。

席位空闲、配置正常时，接入桥核验 Jira 归属、领域门禁、源码映射、独占登记和本机执行者，准备独立 worktree，在可见终端直接启动真实 Claude Run。macOS 使用 Terminal；Linux 自动打开终端需要图形登录和已安装的桌面终端。只有网站授权的调度任务能免去逐单启动确认，旧人工工单的模式保持独立。

需要业务决策时，网页出现待决策事项，并按配置发送通知。正式工程确认仍遵循 Jira 门禁；适用网页确认的事项在网页处理，有效决策交给同一 Claude 会话续传。

Agent 完成 Harness 交付门禁、回写任务并生成完成证据后，自动会话发送 `/exit` 收尾。真实运行结束、进程及租约核验通过后释放席位，再接下一单，不需要人工每天结束每个已完成会话。

### 改派、暂停和异常

- 停用自动执行规则、经办人变化、需求或附件变化、工单移出允许状态时，当前自动任务停止并保留领域状态与证据，通知原负责人处理。
- 忙碌时保留队列，不把等待标为接入失败；网络失败会保留执行状态，避免因不确定结果重复启动。
- 旧版登记或其他席位已取得该 Jira 执行权时，不自动抢占。跨席位改派后需管理员核对旧进程停止并处理交接，当前版本没有自动转移既有独占登记。
- 本机在线还需 Claude 已完成登录、模型配置可用及操作系统允许打开终端。这些本机环境问题会回报检查或请求失败记录。


## 实现与权限

- `server/src/routes/dsp7-jira-dispatch.ts`：配置、PAT 存储/旋转、席位专属凭证获取、自动任务授权、按组织/Jira 去重创建队列。规则授权仅允许席位负责人或管理员，读取 PAT 仅允许该席位独立密钥和匹配机器身份，服务器审计访问。
- `ui/src/components/JiraSeatDispatch.tsx`：席位的 Jira 接单配置页面，项目及仓库列表选择，PAT 不回显。
- 接入桥 `jira_dispatch.py`：分页发现、规则校验、归属变化监控、停止本机执行和保留证据。
- `jira_intake.py`：复用源码/worktree/领域登记门禁；自动申请依赖服务器不可编辑的发现审计记录，人工申请仍依赖人的授权评论。
- `seat_control.py`：心跳回传调度规则、创建一次性启动请求、可见终端直接执行、无逐单名单的规则范围提醒。
- `interactive.py`：真实启动意图和执行租约保护；自动任务生成有效交付证据后退出会话。
- `pilot.py`：运行期获取网页配置的 Jira PAT，沿用本地凭证作为没有网页配置时的来源。

Jira PAT 由系统 local_encrypted provider 加密，普通 adapterConfig 仅保存 secret 引用。请求 payload 使用 `credentials` 整体脱敏，活动日志不记录 PAT。新电脑安装可以跳过本地 Jira 凭证，之后在网页配置 PAT；模型配置仍沿用本机 Claude。网页 PAT 不替换 Claude 自己的 Jira MCP 配置，团队应确保 MCP 和接入桥使用的账号权限一致。
