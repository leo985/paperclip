# 轻舟月度排期叶子节点兼容修复

## 原因

真实轻舟排期树通过 `children: null` 表示没有下级任务的叶子节点。原月度解析器要求非 undefined 的 children 必须是数组，因而拒绝正常响应并显示“轻舟返回内容不符合只读接口合同”。线上只读诊断发现本月响应有 73 个根条目、794 个节点，叶子节点存在 null children。

## 修复

仅在月度解析器中将 null children 视为叶子，兼容空条目根节点。不接受对象、字符串或数值等异常 children；保留组织过滤、完整性校验、身份冲突校验、树深及数量限制。不是通过跳过错误条目来隐藏失败。

## 验证

- 线上私有验证模块使用平台已保存的加密轻舟凭据，真实读取 2026-10 排期，成功返回 73 个条目。未输出密码、PAT 或访问令牌。
- 月度解析与来源接口的 16 项测试通过，新增 null 叶子／空根、异常子节点类型回归。
- 服务端 TypeScript 编译通过。

只发布后端解析模块，无数据库、UI 或席位客户端变化。发布前检查无活动运行并备份旧模块，只重启平台服务；发布记录见同日 monthly-null-leaves-release.json。
