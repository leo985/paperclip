# DSP 交付链快速模拟演练（2026-11-18）

## 目标与边界

在一次性本地 PostgreSQL 中运行真实的交付计划、Jira 经办人到席位匹配、节点依赖调度、问题答复、人工待办、回执版本、进程退出门禁、返工、自动修复与最终验收。虚拟席位立即返回模拟成果；人工动作由测试客户通过原 HTTP 接口办理。数据库在演练结束后清理。

Jira 读取/建单、席位进程及退出证明、正式附件内容是模拟边界。新演练夹具禁止未模拟的外部 fetch，命令不接收线上 URL 或凭据，也不改变线上模板、节点或真实席位。不能据此声称真实客户端领取、Harness 执行、浏览器交互、Jira 连接或部署环境已经端到端验收。

## 使用

```sh
pnpm delivery:simulate
pnpm delivery:simulate --output-dir data/delivery-simulations/manual
```

默认输出到 `data/delivery-simulations/<timestamp>/`：

- `report.json`：总结果、选中测试结果、源码 SHA-256 和证据路径。
- `scenarios.json`：八个场景逐步事件、派发席位、问题/修改意见、耗时及最终验收记录。
- `vitest.json`：原始测试结果，明确区分选中执行和未选择的测试。

命令限定 120 秒；任何场景失败、支持条件不足导致跳过、报告缺失或选中测试数量不匹配均返回非零，不会把“没执行”判为通过。重复运行使用新数据库；显式输出目录只保存本次报告及证据。

## 场景与断言

1. **人机混合链路**：8 个节点、5 个虚拟席位。先占满研发席位验证等待，再释放；设计问题投影为负责人待办，答复返回原运行。人工设计评审退回后派回原设计任务/席位，旧结论失效；两个编码分支并行，全部完成才启动独立评审。人工用例工作及评审、测试启动确认、测试和最终验收闭环。
2. **Agent 评审链路**：设计、编码、用例、测试及独立评审全部由模拟 Agent 完成，工作与评审使用不同席位，最终仍走正式验收接口。
3. **普通代码评审自动返工**：拒绝意见按模板派回原编码任务和席位，在运行上下文中核对完整修改意见，再执行、复审并验收。
4. **普通代码评审暂停**：模板要求暂停时生成恢复待办，由管理员显式发起返工，然后完成闭环。
5. **测试缺陷自动修复**：完整正常前缀后提交结构化失败报告；自动建立 4 个模拟 Jira 单据（缺陷/修复/评审/重测），核对研发实际收到复现步骤及预期/实际结果；独立复审后 QA 必须测试新构建，旧构建回执被拒绝，最终验收。

另外选中既有分析生命周期和完整串行链路测试，验证需求分析提问/确认、精确版本评审/发布以及分析到后续阶段的交接。串行链路的分析发布状态由原夹具模拟；分析协议本身由独立生命周期测试通过 HTTP 验证。没有把整个测试文件中未选择的用例计为通过。

## 演练发现与修正

- 返工清理下游输入版本后，尚未确认启动的节点可能留下空版本，无法通过确认接口。调度器现在以同一函数计算确认和实际派发的输入摘要；待办投影在摘要尚未准备好时不显示无法办理的启动确认。
- 普通独立代码评审拒绝时原来一律阻塞，没有遵循模板的自动返工策略。现在记录带完整意见和成果版本的拒绝结论，复用既有返工协议；自动策略派回原研发席位，暂停策略保留人工恢复，节点累计返工达到 3 轮后转人工处理。
- 两个既有测试夹具适配当前规则：分析测试登记实际组织管理员成员；串行链路用“不接单”标记表达不可调度，不再仅凭 `busy` 状态推断并发名额已满。

本次不修改项目模板协议、数据库结构或客户端协议。上述修复尚未发布线上。

## 席位离线与重新上线补充演练

新增三个完整闭环场景，均由真实调度器/HTTP 接口处理，并最终验收：

1. 派发前心跳过期：保持当前任务等待，不创建运行；原席位恢复心跳后仅派发一次并完成交付。
2. 执行中短暂失联：保留原任务、运行和授权，不重复派发，不提前启动下游；负责人在离线期间的答复保存在实例中，席位重连后读取原答复并继续交付。此场景假设原进程仍存活且执行许可未到期。
3. 执行中终止：模拟运行失败后节点进入中断/恢复待办；仅上线不会重新派发。未证明旧进程树停止时，恢复接口拒绝操作；停止核验及管理员恢复后，在原任务和原席位建立新运行，旧授权不可再用，最终完成交付。

这是控制面模拟，不是实际拔网线/关机的真实席位实验。客户端执行许可失效会主动停止进程，不能承诺无限期断网后自动续跑。`harness offline` 的安全下线另有排空语义：暂停新任务，活动会话结束后下线，不主动中断当前 Claude 会话。

最新执行：`data/delivery-simulations/2026-11-18T01-25-25-324Z/report.json`，10/10 选中测试通过（八个完整演练场景和两个分析/串行协议测试），耗时 14.69 秒；21 个未选择用例不计通过。客户端执行许可的 6 个单元测试通过，服务端 TypeScript 及脚本语法检查通过。本次仅补充演练，未修改恢复策略、未发布线上，也未操作真实席位。
