# 协同工作台项目筛选

日期：2026-10-24

## 行为

在现有“我的工作 / 组织概览”旁增加项目选择，支持全部、具体项目（含归档标记）、未关联项目。复用 Dashboard 的现有项目查询，不新增轮询。项目条件保存在 URL 的 projectId 参数，支持刷新及带条件跳转；切换组织重建工作台组件，不继承个人范围状态。

工单、数量和工单关联提醒按项目过滤；席位级提醒和组织待审批保持可见并标注独立范围，不计入项目工单数量。无法确认归属的工单关联提醒不混入所选项目。项目查询失败保留条件并显示提示，不自动扩大工单范围。

打开工单列表传递项目参数。具体项目沿用后端既有 projectId 分页和搜索过滤，避免按加载页局部过滤。未关联项目复用组织完整工单列表查询并筛选，搜索限定该结果集；不会向服务端发送特殊值作为项目 UUID。列表顶部明确当前条件并提供清除入口。已有工单列表的其他持久化筛选继续适用。

## 发布与验证

仅前端与在线帮助修改，无数据库、后端及席位客户端改动。类型检查、构建、token 检查及差异空白检查；发布前备份与基线检查，发布后核验静态资源校验和、健康接口和服务 PID。不发起真实任务或模型调用。
