# 主子工单树形表格

来源核对及条目“工单与执行”共用的 `DeliverySourcePlan` 改为使用 `DeliveryWorkTree`，按真实 parentKey 将子单归入主工单，不重复展示父编号列。

- 主行展示标题、来源状态、经办人和子单完成数，子行缩进保留类型／标题、状态、经办人及排期。
- 父单已发布但仍有待办子单时默认展开；父单及全部子单均完成时默认收起。无子单明确说明并禁用展开按钮。
- 支持单分支、全部展开／收起；搜索编号、标题、类型、经办人及来源状态，搜索时保留父级并展开匹配分支，清空恢复此前手动状态。
- 完成数仅依据来源状态，不替代正式交付或验收。异常缺失父级的子单单独提示，不静默丢失。
- 原生表格保留表头，展开按钮提供 aria-expanded、aria-controls 和明确名称，可用键盘操作；窄屏在表格容器内横向滚动。

验证：两项组件回归测试、UI 类型检查、设计 token 检查、构建通过；ego-browser 使用真实组件验证分支及全部展开／收起、匹配子单保留父级、搜索后恢复手动状态、无匹配提示。帮助同步说明树形交互。

仅发布静态 UI 及帮助，不更改后端、数据库或席位客户端，不重启平台服务。发布记录见同日 delivery-work-tree-release.json。
