# Jira 接单范围交互完善

## 修改

- 将状态与类型分成有独立 legend 的两个 fieldset，分别说明“什么时候执行”与“执行哪些类别”。
- Jira 状态使用关键词搜索与有限高度滚动列表，响应式 1/2/3 列；保留 Jira 原始名称供查询。
- 已选状态独立展示，不受搜索筛选影响，可单项移除、清空；对齐服务端最多 20 个状态的限制。
- 输入原始状态名称移到高级折叠区，与复选框是同一配置，去重后保存。
- 工单类型增加说明与已选汇总，保持原配置和默认值。
- 底部给出当前经办人、项目、类型、状态的自然语言范围摘要，强调所有条件同时满足。
- 搜索只影响展示，不触发配置未保存状态；不自动选择状态、不自动保存或启用规则。
- 帮助中心补充实例与操作步骤。

## 验证与发布边界

前端类型检查与 UI 构建通过。仅更改前端和帮助，不修改服务器 Jira 查询、领域门禁或已保存调度配置。本次未新增或运行测试套件，也不触发真实 Jira 工单执行。发布保留原 UI 备份，核对静态资源与健康状态。
