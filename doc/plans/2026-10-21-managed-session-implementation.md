## 隐私和控制

- 对话使用独立私有资源，工单可见性不自动授予正文权限，其他 Agent 无权读取。用户仍须具有组织访问权。
- 在分块前完整文本脱敏；排除凭据路径及指定工具，关联工具输出继承排除规则；终端跨写入先合成完整行；附件仅接受允许目录中的非符号链接 UTF-8 文件。
- 服务端二次检查，原生配置不上传。密钥规则不是通用 DLP，不承诺识别任意自定义机密；可用 `managed_collection.excluded_paths`、`excluded_tools` 增加项目排除。
- 采集正文不进入第一方遥测、Sentry、通用 HTTP 请求／错误正文、运行完成摘要或搜索。私有命名空间的 malformed JSON 和错误请求亦不开放日志正文。
- 暂停上传仍采集到本机；暂停采集会排除暂停区间，恢复不补采，半行残留不会作为新记录上传。平台删除清理正文副本与投影、保留墓碑；收到墓碑的客户端清理该采集队列。原生 Claude 历史文件不属于平台删除范围。
- `DSP7_MANAGED_SESSIONS_ENABLED=false` 可应急关闭新增采集写入，不重启领域任务；本地队列继续受容量限制。恢复写入后按确认位置续传。
- 正文默认保留 90 天；当前由新会话登记触发，每小时最多清理 100 个到期会话。不得描述为精确到期定时清除。

## 尚未覆盖及必须验收的边界

1. **二进制附件**：图片、PDF、内嵌文档暂仅提供元数据／不可用原因。尚无格式脱敏器和二进制下载接口。
2. **跨轮原生会话**：当前执行器每个 run 创建独立 native session；同轮 Stop Hook 续传可继续，跨 run 复用原生会话明确拒绝。绑定表预留多轮关系不代表已经支持。
3. **领域契约**：提供可信门禁执行出口，但未替所有现有编码／设计技能编制完整阶段契约。现有 state/effort 只显示观察状态，无通过推断或伪造百分比。
4. **首次离线登记和转交**：首次绑定须在平台运行活动期完成；未成功绑定即结束时，仅本机留存，不伪造事后绑定。负责人变更仅允许已冻结、结束会话在七天内按原始边界补传；尚未收到结束边界的旧会话会被拒绝扩展，需要诊断处理。
5. **跨平台及解析版本**：协议／解析器为 v1，尚未进行 macOS、原生 Windows、Linux 的真实 Claude 兼容验收；没有已验收版本矩阵。未知结构、缺失来源和超限会产生缺口。
6. **保留与容量**：未提供组织自定义保留策略、独立定时清理和一年元数据清理。正文每条／文件 100 MiB、附件累计 1 GiB、平台每会话正文分块 2 GiB；本机待传队列默认 1 GiB，记录无法容纳时暂停该来源而不跳过。未实现小时级全量来源核对，当前使用增量游标及结束补扫。
7. **质量和统计**：只覆盖接入后的事实和有明确信息的 Jira 关联；不反推历史工时、任意 Tracker 缺陷或隐藏会话。Jira 关联超过 100 条不提交部分结果冒充完整快照。统计自然时间中的未知包含离线／未接入时间，不能当考勤指标。
8. **验收缺口**：未运行单元测试、集成测试、浏览器或真实终端测试；未触碰真实 Jira 状态、发送消息或调用模型。权限、断网、删除、长正文、跨期和负责人转交需要后续专门验收。
