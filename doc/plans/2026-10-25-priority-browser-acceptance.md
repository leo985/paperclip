日期：2026-10-25。状态：持续实施中，未全部完成；本批未发布生产、未升级真实席位。

## 验收环境

- ego-browser 任务空间 79，沿用原验收空间；本次用户明确要求真实浏览器测试后恢复控制。
- 本机隔离实例 `http://127.0.0.1:3100`，组织“交付验收测试”；独立临时数据库，不连接生产数据。
- 浏览器页面实际执行选项选择、键盘激活按钮、上传 JSON、预览、保存、比较、提交说明。窗口最小化时截图失败，故记录语义页面和真实响应，不声称视觉截图验收通过。
- 测试席位名称包含“隔离夹具”，暂停且无真实执行凭据。用量/停止记录是明确的状态夹具，不冒充实际业务派单或 OS 停止回执。

## P0：补齐浏览器验收及修复

- 同领域两套分析 Harness：选择第二套、保存并刷新后保持选择；研发仅一套时自动选中。
- 执行记录：未知不展示零消耗；部分用量显示输入 100、输出 20、缓存 10；最终对账显示累计 150、25、10。停止待核验与已回报受管树停止证明分别显示；未计价费用不转换为已知账单。
- 浏览器实际暴露 `SeatRunControl` 与 `RunLogPreview` 的兄弟元素 key 相同；分别增加 control/log 前缀，防止运行切换时 React 错误复用。重验三条记录切换，服务日志没有重复 key 警告。
- 这些通过的是本机浏览器功能验收；Windows 真机、正式席位的新客户端闭环和生产验收仍待完成。

## P1：版本比较

- 新增公司隔离的快照比较 API，只允许同项目、同来源、同条目的不同已保存版本；跨组织不可访问，跨范围拒绝。
- 比较条目标题/状态/身份、负责人、主单来源身份、成员新增/移出、父子关系、类型、标题、经办人、状态、排期及结构核对差异。顺序改变不产生伪差异，历史版本不修改。
- “条目交付”新增基准版本、对比版本和变化表格，显示采集方式变化。当前候选范围为快照列表当前页，尚不支持跨页同时选择。
- 浏览器：上传并预览/保存两个不同快照，选择 08:00 → 09:00 版本，正确显示 3 项变化：ATSES-2 状态“已作废 → 开发中”、经办人“未提供 → 新负责人”、作废结构差异消失。
- 此功能是规范化快照比较，不声称原始附件/正文比较、正式准入核验或持续同步已经完成。

## P1：核对说明审计

- 管理员可对同范围版本提交最多 2000 字核对说明；成员仅可比较。服务端重新核验组织、项目和两个不可变版本，审计保存版本指纹、记录人与说明。
- 仅生成审计记录，明确 `formalApproval=false`、`executionGranted=false`；不把 activityLog 当作领域差异解决状态。
- 浏览器：填写说明、提交，页面显示“核对说明已记录到审计日志；未批准交付、取消或派发任务”。权限和空说明拒绝通过定向 API 回归验证。
