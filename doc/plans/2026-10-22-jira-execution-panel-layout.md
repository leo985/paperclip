# Jira 工单执行区域交互调整

区域改为“Jira 工单执行”；右侧按钮为“接入其他工单”（无当前任务时为“接入 Jira 工单”），仅展开表单。

当前接入任务显示为独立卡片，展示实际任务编号、标题、状态和席位。查看详情与当前任务操作分开排列；恢复按钮明确显示“恢复 DSP-xx”，首次执行按钮显示“执行 DSP-xx”。任务详情页恢复入口同步命名。运行编号折叠到“技术详情”。

填写接入表单不再清除当前任务卡片；重复输入当前工单会引导回原任务，不创建或重复派单。恢复成功会刷新任务状态。独立 Jira 入口和在线帮助同步更新文案。

本次只发布前端静态资源，无后端、数据库和席位客户端更新，不触发任务执行。使用 UI TypeScript 编译、生产构建与设计 token 静态检查，不运行测试。
